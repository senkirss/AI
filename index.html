POP-UP DI HALAMAN LAIN

Pakai asisten di tab ujian / web lain

Popup bawaan browser hanya hidup di web ini. Untuk memakainya di halaman lain (tab soal, LMS, PDF online), pakai salah satu cara ini — tanpa install extension:

A Bookmarklet (1 klik)

  1. Tampilkan bookmark bar (Ctrl+Shift+B)
  2. Drag tombol ini ke bookmark bar: 🤖 Akutansi AI
  3. Buka halaman soal → klik bookmark itu → popup muncul di pojok kanan

B Jendela terpisah / embed

Tempel kode embed di console (F12) halaman soal, atau simpan sebagai bookmarklet manual. Key 🔑 tetap per-browser.
